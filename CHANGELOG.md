# Changelog

All notable changes to Asset Map. Versions follow [semver](https://semver.org).

## [0.1.0] — unreleased
### Added
- Offline single-folder HTML app opened from `file://`.
- CSV data folder loading (employees, assets, types, settings, incident) with drag/drop, folder picker and "remember this folder".
- Offline geocoding: lat/lon → postal code → city → country centroid, with match level per record.
- Vector basemap, offline terrain tiles, optional online Esri street/terrain/satellite layers.
- Bubble clustering for people; typed shape/colour markers for physical assets.
- Incident with any number of named markers (Fire 1, Fire 2 …), shared or per-marker rings, save/load/reset.
- Dark and light theme.
